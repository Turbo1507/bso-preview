# BSO v2 — что это и как поддерживать

Вторая версия лендинга Black Sands Oasis: тёмная тема на `#131313` с золотым
градиентным акцентом. Живёт рядом с v1, **v1 не трогает**.

* Живая: `https://turbo1507.github.io/bso-preview/v2/`
* Источник темы: Figma, страница «БСО 2», фрейм `бсо2` = node `6:651`
  (channel `5hk0d9xc`) — чужая наработка, которую попросили совместить с нашей.
* Прототип блока 3 от Босса: там же, фрейм `block3_redesigned_prototype` = `275:715`.

## Как устроено

v2 — **не копия** v1. Общее берётся на уровень выше:

| Файл | Откуда |
|---|---|
| `../css/styles.css` | вся раскладка v1 |
| `../js/i18n.js`, `../js/main.js` | словарь и интерактив v1 |
| `../assets/` | все фотографии |
| `css/v2.css` | только тёмная тема + новые блоки |
| `js/v2-i18n.js` | строки новых блоков, мержатся в `window.I18N` |
| `js/v2.js` | аккордеон FAQ + подключение карусели галереи |
| `js/legal.js` | RU/EN для `consent.html` и `legal-info.html` |

Два хука в общем `../js/main.js`, оба выключены, если страница их не объявила
(v1 работает как раньше):

* `window.BSO_ASSET_PREFIX = '../'` — пути `assets/...` внутри `main.js`
  считаются от страницы, а v2 лежит на уровень глубже.
* `window.BSO_NUANU_BADGE_PIN = {dot, from}` — точка и указатель у бейджа
  BLACK SANDS OASIS на мастер-плане (в v1 бейдж без пина).

## Перед каждым деплоем — бампить `?v=`

GitHub Pages отдаёт `Cache-Control: max-age=600`. Без версии в ссылке браузер
до десяти минут подтягивает старые css/js к новой разметке — выглядит так,
будто «пуш не докатился». Поэтому во всех трёх html стоит `?v=ГГГГММДДб`
на `styles.css`, `v2.css`, `i18n.js`, `v2-i18n.js`, `main.js`, `v2.js`,
`legal.js`. **Меняешь любой из этих файлов — подними версию во всех ссылках**
(разом: `scratchpad/cachebust.py`, там одна константа `V`).

Сам `index.html` всё равно кэшируется на те же 10 минут — этим на Pages не
управлять, поэтому сразу после деплоя первый заход может показать старую
страницу. Лечится жёсткой перезагрузкой (Ctrl+Shift+R).

## Чем `index.html` отличается от `../index.html`

Если v1 перепишут заново (так уже было — его переводили на «английский как
основной»), отличия придётся перенести руками. Полный список:

1. Пути ассетов `assets/` → `../assets/`; стили и скрипты — на уровень выше
   плюс свои; `canonical`/`og:url`/`hreflang` ведут на `/v2/`.
2. Убран служебный переключатель темы «Цвет/Моно» и его бутстрап-скрипт —
   тема одна.
3. Объявлены `BSO_ASSET_PREFIX` и `BSO_NUANU_BADGE_PIN` до `main.js`.
4. **Блок 04 (карусель преимуществ) заменён на блок «Виллы в комплексе
   будущего»** — сетка 1fr/1fr, слева высокая карточка «6-метровые потолки»
   на три ряда, справа три. Фото — `villas-*.jpg`, вытащены из прототипа Босса.
5. Подписи `.min-foot` переехали ВНУТРЬ `.min-gallery` как `.min-gallery-notes`
   (стеклянные карточки на фото).
6. Чипы `.signature-chips` переехали ВНУТРЬ `.signature-photo` — одной
   стеклянной строкой на кадре Stella Solaris.
7. У «Частной территории» фото `villa-2bd-detail1.jpg` заменено на
   `villa-private-pool.jpg`: в первом спальня с рабочим столом, а alt обещает
   приватный бассейн.
8. Карточке Анны Орловой добавлен класс `team-card--anna` — на EN она скрыта.
9. Добавлены секции «Галерея проекта» (`#gallery`) и «Ответы на вопросы»
   (`#faq`), в три меню добавлен пункт «Вопросы».
10. `consent.html` и `legal-info.html` переписаны: RU/EN через `js/legal.js`,
    правильные пути к стилям (копии из v1 ссылались на несуществующий
    `css/styles.css` и открывались без оформления вообще).
